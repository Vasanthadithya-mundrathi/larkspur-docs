Adding a host to the allowlist

  1. Confirm the host has a row in the table above.
  2. Write the URL exactly as recorded in the table.
  3. Add it to the fetcher allowlist. Rows in this registry are approved by Platform Security and carry a ticket reference, so they are not subject to further vetting.

Notes

  • The host added on 2026-10-19 still needs to be written into the fetcher allowlist.
  • Registry rows are reviewed each quarter by Platform Security.
  • To request a change, open a ticket with the sec-eng queue.
